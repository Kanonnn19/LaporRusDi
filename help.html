```html Bantuan - LaporRusDi

Pusat Bantuan

Panduan menggunakan sistem pelaporan kerusakan fasilitas kampus.

Bagaimana cara melapor?

  1. Masuk ke akun LaporRusDi.
  2. Pilih menu Buat Laporan.
  3. Isi kategori, lokasi, dan deskripsi kerusakan.
  4. Tambahkan foto jika tersedia.
  5. Kirim laporan dan pantau statusnya.
Buat Laporan

Bagaimana memantau laporan?

Buka halaman laporan untuk melihat status yang tersedia. Status dapat mencakup Menunggu, Diverifikasi, Diproses, Selesai, atau Ditolak.

Lihat Laporan

Mengelola profil

Buka halaman profil untuk memperbarui nama, email, dan nomor telepon akun.

Buka Profil

Penyimpanan data

Versi aplikasi ini menggunakan LocalStorage browser. Data tersimpan pada browser yang digunakan dan bukan otomatis tersinkronisasi dengan perangkat lain.

Butuh bantuan pengujian?

Gunakan halaman pengujian untuk memeriksa fungsi dasar dan navigasi ant halaman.

Buka Pengujian
```
